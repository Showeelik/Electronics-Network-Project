# Сеть по продаже электроники

Веб-приложение для управления иерархической структурой сети по продаже электроники.

## Требования

- Python 3.8 или выше
- Poetry
- PostgreSQL

## Установка

1. Клонировать репозиторий:
```bash
git clone <url-репозитория>
cd electronics_network_project
```

2. Установить зависимости с помощью Poetry:
```bash
poetry install
```

3. Применить миграции:
```bash
poetry run python manage.py migrate
```

4. Создать суперпользователя для доступа к админ-панели:
```bash
poetry run python manage.py createsuperuser
```

## Запуск

```bash
poetry run python manage.py runserver
```

После запуска админ-панель будет доступна по адресу http://127.0.0.1:8000/admin/

API доступно по адресу http://127.0.0.1:8000/api/

## Модель данных

Приложение реализует иерархическую структуру сети по продаже электроники:
- Завод (уровень 0)
- Розничная сеть (уровень 1)
- Индивидуальный предприниматель (уровень 2)

Каждый узел сети содержит:
- Название
- Контактную информацию (email, страна, город, улица, дом)
- Продукты
- Ссылку на поставщика
- Задолженность перед поставщиком
